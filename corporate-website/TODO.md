# 官网优化待拓展清单

> 已完成 P0–P3 全部优化项（共 17 项），以下为后续拓展方向，按需启动。

## P4：功能拓展系列

### P4-1 产品对比功能
- 产品列表页增加"加入对比"勾选框，最多选 3 台设备
- 底部悬浮对比栏展示已选设备，点击"开始对比"跳转对比页
- 对比页用表格横向并列展示：型号、价格区间、包装速度、电压、功率、设备尺寸、适用行业等关键字段
- 差异高亮：不同值的行标记背景色
- 复用 `fetchProductDetail` 接口，对比数据全部前端组装，无需后端新端点

### P4-2 中英双语
- 接入 vue-i18n，提取现有中文文案到 `locales/zh.json` + `locales/en.json`
- Header 增加 `中文 / EN` 切换按钮，存 localStorage
- 后端 API 需新增 `lang` 参数支持英文数据返回（产品名、摘要、分类等）
- 优先翻译：首页 Hero、产品名、导航、CTA 按钮；详情页长文本可分阶段翻译
- 注意：SEO 需配套 `hreflang` 标签

### P4-3 下载中心
- 新建 `/downloads` 路由 + Downloads.vue 页面
- 展示产品手册、检测报告、资质证书 PDF 等可下载资源
- 后端新增 `GET /api/website/downloads` 接口，返回公开的文件列表
- 前端按类型分组（产品手册 / 检测报告 / 企业资质 / 其他），支持关键词搜索
- 文件链接走 `/api/file-assets/{id}/download`，需后端开放公开访问权限

### P4-4 视频嵌入
- 产品详情页增加"产品视频"区块，位于图库下方
- 后端 ProductModel 新增 `videoUrl` 字段（支持上传或外链）
- 前端用 `<video>` 原生标签或 iframe（外链）嵌入
- 首页 Hero 区可选支持背景视频（mp4），通过 Banner 配置切换
- 注意移动端自动播放限制：静音 + playsinline
