# 经销商信息导入（氚云导入中心第七类数据源）

> 2026-09-14 建成。补的是此前的空白：氚云「经销商信息」表单在系统里没有任何落点。

## 一、为什么需要它

| 现状 | 数值 |
|---|---|
| 经销商此前只有自由文本 `sales_outbounds.dealer_name` | 97 种写法，**无编号** |
| 客户档案里能精确命中的经销商名 | 28 / 97 |
| 提成体系已在依赖这个字段 | `CommissionPolicy` 用「填了经销商 或 毛利率<15%」区分经销商单/零售单 |

导入这份台账后，经销商第一次有了**权威主档 + 业务键**（氚云经销商编号 `JXS…`）。

**关键验证**：台账 188 条，与出库单 97 种 `dealer_name` 写法 **97/97 精确命中** —— 这份台账就是那批自由文本的主数据来源。

## 二、落点与架构

新增第七类导入种类 `DEALER`，归 **B 域台账**（与产品信息、仓库明细同构），完全复用既有批次管线：

```
上传 → 登记批次(UPLOADED) → 异步解析 → 落暂存 → 与台账逐行 diff → 预览(PREVIEW_READY)
                                                                        ↓ 确认
                                                          新增 / 更新 / 无变化（不删除、不覆盖历史行）
```

| 层 | 文件 |
|---|---|
| 建表 | `V294__create_h3_dealer_catalog.sql` |
| 种类契约 | `ImportKindDescriptor.DEALER`（route=`dealer`，dbType=`DEALER`，展示名「经销商信息」） |
| 解析/比对/写入 | `ProductInventoryLedgerImportService`（`Kind.DEALER` + `parseDealer/dealerEqual/applyDealer`） |
| 台账读取 | `ProductInventoryMergeService.dealerLedger / dealerDetail` |
| 读端点 | `GET /api/h3-imports/ledger/dealer`、`/ledger/dealer/{id}` |
| 写端点 | `POST /api/product-inventory/dealer/stage`、`/ledger-batches/{id}/confirm` |
| 前端 | `constants/h3Import.ts`（导入卡）、`H3ImportCenterView`（台账 Tab）、`H3LedgerPanel`、`H3ImportPreviewDialog`、`H3LedgerDetailDrawer` |

数据库表 `h3_dealer_catalog`：`dealer_code` 唯一键；`source_hash` 做行级变更判定；保留氚云源字段（数据ID / 数据标题 / 拥有者 / 创建人 / 源创建、修改时间）以便溯源。

## 三、Excel 列位映射（列位固定，两行表头）

氚云导出为**第 1 行英文字段码 + 第 2 行中文列名**，数据从第 3 行起。与产品信息/仓库明细同约定，不做表头识别。

| 列 | 中文表头 | 落库字段 |
|---|---|---|
| 0 | 修改时间 | `source_modified_at` |
| 1 | **经销商编号** | `dealer_code`（业务键） |
| 2 | 联系方式 | `contact` |
| 3 | 经销商名称 | `dealer_name` |
| 4 | 经销商地址 | `address` |
| 5 | 备注 | `remark` |
| 6 | 归属业务员 | `owner_salesperson` |
| 7 | 数据状态 | `data_status` |
| 8 | 附件 | 忽略 |
| 9 | 数据ID(不可修改) | `source_object_id` |
| 10 | 数据标题 | `source_title` |
| 11 | 拥有者(必填) | `owner_name` |
| 12 | 所属部门(必填) | `department_name` |
| 13 | 创建人 | `created_by_name` |
| 14 | 创建时间 | `source_created_at` |

> 时间列在 Excel 里是**文本**（`2026-08-17 10:24:41`），入库转 `DATETIME`；行级比对按「解析后比较」，避免每次重导都误判成"更新"。

## 五、在界面上的位置

氚云导入中心（`/h3-imports`）：

- **导入**：导入卡新增「经销商信息」紫色卡（主档台账组），与产品信息/仓库明细并列；上传 → 比对预览（逐行 新增/更新/无变化，带中文变更标签）→ 确认写入
- **历史台账**：Tab 新增「经销商」，可按编号 / 名称 / 联系方式 / 归属业务员 / 地址搜索，点击「详情」查看台账字段 + 氚云源字段
- **导入向导**：第 2 步改为「建立产品、仓库与经销商基线」，日常更新步骤也加入经销商

## 六、后续（尚未做）
