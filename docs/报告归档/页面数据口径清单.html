FACT_RECEIPT_PREDICATE（用于 receipts 表别名 r）
r.legacy_migrated_tag IS NULL → 排除 V171 打标的 92,625 条 OUTBOUND_EMBEDDED 已迁出快照收据 （legacy_migrated_tag = 'MIGRATED_OUT_TO_SNAPSHOT'）
FACT_ALLOCATION_PREDICATE（用于 receipt_allocations 表别名 ra JOIN receipts r）
ra.allocation_origin = 'DIRECT' AND r.legacy_migrated_tag IS NULL → 双重保险： ① allocation 端排除 OUTBOUND_EMBEDDED 打标分配 ② receipt 端再次排除历史迁移行
