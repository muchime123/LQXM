# 生产任务配置与入库产品命名梳理

日期：2026-09-27。范围：当前数据库只读走查与现有代码核对；未修改产品名称、库存余额、产品关联或历史单据。
氚云导入数据作为参考样本与口径验证场，不作为未来 ERP 产品主数据的自动权威来源。

## 1. 结论

生产任务中的“产品名称”应作为基础产品/机型选项；入库产品名称应由该选项及经确认的产品配置生成。产线用于确定可选产品范围和命名模板，通常不写入成品名称。制程用于执行，不写入成品名称。

同时保留三层信息：

1. 基础产品名称：如 LQ370气调机卷膜、LQ750D全自动多模具。
2. 入库显示名称与完整规格：告诉仓库和销售实际是哪件货，由结构化配置生成。
3. 唯一产品编号/ID：用于单据关联及库存聚合。名称不是唯一键，不要求不同产品名称绝对不同；同名时必须显示编号和规格。

“品类＋尺寸＋一出N”只能作为名称的一部分，不能证明产品身份相同。

## 2. 当前数据与链路

| 表/字段 | 当前含义 | 对命名的作用 |
| --- | --- | --- |
| manufacturing_task_config_items：workshop_id、config_type、config_name | 按产线维护产品名和选配 | 决定基础产品与可选配置范围；目前还没有完整的型号、命名模板、选配分类字段 |
| production_orders：production_line、product_name、box_size、box_shape、mold_layout、voltage、plug_type、brand、optional_configuration | 氚云任务源数据 | 验证真实生产配置和脏值，保留原文 |
| manufacturing_orders：workshop_type、product_name_snapshot、product_config_json、specification_snapshot | 当前执行任务与配置快照 | product_name_snapshot 当前主要还是基础名；完整配置保存在 JSON |
| manufacturing_order_outputs | 一张任务的产出清单 | 机器、额外模具等应分行确认库存产品身份 |
| h3_product_catalog：product_code、product_name、specification、unit | 氚云产品信息台账 | 历史入库名的主要参考样本 |
| h3_warehouse_stock：warehouse、product_code、product_name、specification、unit | 氚云仓库库存台账 | 检查实际有货名称与产品信息是否一致 |
| purchase_receipt_items：product_code、product_name、spec、unit、production_order_no | 历史入库明细，包含部分任务号 | 提供实际入库写法与追溯线索；不能把全部行当成自产产出 |
| sales_products | 当前交易/库存产品身份 | 承载可选产品编号、名称与规格；目前缺少完整结构化任务配置身份 |
| product_inventory_balances / transactions | 本地库存余额与流水 | 按产品身份与单位记账；流水保存入库当时名称和规格快照 |

走查数量：任务源 5,691 行，产品信息 15,304 行，仓库库存 16,319 行，sales_products 4,920 行；历史入库明细 63,818 行，其中任务号非空 6,681 行（非空不等于已成功关联）。

产品信息中 4,147 行规格为空、8 行名称为空；133 个非空名称对应多个不同产品编号。产品信息与仓库库存按编号连接时，有 54 条仓库非空名称与产品信息名称不同。数量为本次查询时点快照。

例：编号 132BZDQTJ 在仓库中是“LQ750-2014一出四连续式+自动进盒（7字型）”，产品信息中却是“LQ370-2219一出二真空模具”。这种记录必须待核对，不能仅按编号或名称自动认定是同一种货。

## 3. 样本暴露的命名问题

| 真实样本 | 问题 | 新规则 |
| --- | --- | --- |
| LQ750D-153x114一出四多模具连续式+灌装（直流式）+自动卷膜+简单封口 | 型号、尺寸、出数、功能挤在一串里 | 结构化存储，同一顺序生成展示名 |
| LQ260-φ90一出四PLC-40泵 | 控制器、泵型是区分配置的关键内容 | 显式保存控制方式和泵型，不能只认尺寸与出数 |
| 2014、2617*8、38*27 32*24 | 缩写、单位和多尺寸混用 | 不能猜测 2014 就是 200×140；有依据确认后才能转换 |
| LQ450-4020一出二PLC-63泵+1812一出六真空模具一套 | 一台机器和额外模具混为一个名字 | 主机与额外模具分产出行，组合关系另存 |
| 140气动一出四上下模具（对应两个编号） | 同名不足以说明图纸/适配关系相同 | 编号区分，核对适配机型、模具结构及版本 |
| 木箱、出口木箱与 PLC、40泵混在同一选配列表 | 交付包装与机器技术配置混杂 | 将选配分组，不把所有选配机械拼入产品名 |

还看到本地任务配置中有形状、电压等填写为“1”的记录；以及 boxSize 为 128x184、结构化长宽为 184/128 的旧记录。这些可能来自测试或旧规则，未判定其业务有效性；不能直接拿来建立规范产品。

## 4. 建议统一的名称写法

### 4.1 机器

建议仓库展示完整写法：

`基础产品名｜盒型与尺寸｜模具排列｜关键技术选配｜电气与品牌`

完整规格同时列出盒高、适用盒材质等未在名称中展开的字段。名称和规格由同一份配置生成，不分别手工修改。

示例（说明规则，不代表现有数据已确认）：

- `LQ370气调机卷膜｜方盒200×140mm｜1出4｜PLC+40泵｜单相220V/美标/中性`
- `LQ750全自动推杆｜方盒186×136mm｜1出4｜简单封口+特氟龙+出盒4变1｜单相220V/国标/利强品牌`
- `气动片膜｜圆盒Φ250mm｜1出2｜单相220V/国标/利强品牌`

产品选择列表必须同时展示产品编号、完整规格、单位。电气、品牌等若从短名称省略，也必须在同一行规格中可见，不能因“默认配置”隐去其实际值。

基础产品名仍沿用任务配置中的选项，不靠去掉后缀、替换词语或匹配旧库存名来猜型号。

### 4.2 模具

`适配基础机型｜模具用途/类型｜盒型与尺寸｜模具排列｜关键结构/版本`

示例：`LQ260｜真空上下模具｜圆盒Φ84mm｜1出4｜图纸版本A`。

必须补齐：适配机型、上下/内/中间模具等类型、成套或单件、图纸/设计版本；必要时包含盒高、盒口轮廓、材质适配、易撕口结构。盒子长宽相同不代表模具一定可互换。

“模具”只是产品大类，不能独自成为最终入库名称。

### 4.3 配件

`配件标准名称｜型号/规格｜适配机型（需要时）`

不能把“配件”直接作为可选库存品，也不应强制沿用机器的盒尺寸、出数等全部必填字段。

### 4.4 机器、附加模具与包装

- 随主机安装的标准模具：体现在主机配置中，避免同一实物重复入库。
- 额外可独立交付的模具：独立产出行、独立产品编号、独立单位。
- 整套设备作为一个库存组合：需要明确套件清单及计量规则，不能靠一个超长名称代替组成关系。
- 木箱/出口木箱：先作为包装与交付要求保存；若公司实际单独管理包装件库存，则包装件另行入库，不直接改变机器身份。

## 5. 字段处理原则

| 字段 | 建议 |
| --- | --- |
| 产线 | 控制基础产品与命名模板范围，独立字段；通常不进名称 |
| 产品名/型号 | 名称核心，使用稳定选项 ID；名称可修订并保留业务快照 |
| 盒形与尺寸 | 方形长×宽，圆形 Φ直径，单位 mm；异形用说明及图纸引用，不自动转方形 |
| 盒高 | 单独结构化记录；是否区分主机/模具身份按产品类型确认 |
| 一出N/排列 | 同时记录排列原值与规范出数；不能把“2出1”未经确认转换成“1出2” |
| 盒材质 | 指包装盒材质，不是机器机壳材质；是否影响模具/设备互换需要技术判断 |
| 技术选配 | 分组管理：控制器、泵型、封口模式、灌装、进出盒、打码、机壳等；同组选项需互斥校验 |
| 电压/相数、插头、品牌 | 完整保存并展示；差异可能影响是否可直接交付替代 |
| 配置说明 | 保存原文与附件；影响制造或互换的要求提取为字段/图纸版本，不能只靠说明判断同款 |
| 客户、业务员、任务号、交期、仓库 | 保留在单据、批次和归属中，不用于产品名称或产品编号 |
| 常规/订做 | 单独判定与保存，不能用名称里有无“订做”判断 |

规范化只做有依据的转换：如“单项220V”→“单相220V”、“利强牌”→“利强品牌”。历史原值必须保留；2014、2617、方形却填单数字、多套尺寸等均进入待确认清单。选配按固定分类和顺序生成，不能随用户勾选顺序改变名称。

## 6. 当前实现缺口及落地顺序

已核对代码：新建任务保存基础名与完整配置 JSON，但前端 specificationText 主要生成尺寸和盒高；完工检验仍需选 sales_products 的库存身份。已有名称拼法并没有形成统一的后端命名服务。不能宣称系统已按完整配置自动生成入库产品名或自动确认同款。

1. 先在“任务单产品与配置”补产品类型、基础产品稳定 ID、型号及命名模板；同一产线内机器/模具/配件使用各自字段规则。
2. 将现有选配分为技术、附件、包装三组，规定互斥与显示顺序。保留已有原始选项与历史任务快照。
3. 在销售配置/独立任务的同一表单里预览“预计入库名＋完整规格”，统一后端生成与校验；不新开第二套录入页面。
4. 完工检验依据实际产出确认产品身份：相同且可互换时复用已有编号，不同或无法判断时新建/待确认。主机和额外模具分行处理。
5. 入库、库存选货与销售出库全部引用产品 ID，并展示统一名称和规格；单据保留当时快照，历史原名作为别名/来源信息。
6. 先用全自动气调机车间的少量真实任务试跑，再扩到半自动、封口机、称重机。称重产品应有量程、精度等专属规格，不能强制套盒子尺寸模板。

验收：相同确认配置的名称生成顺序一致；改变关键选配能够看出差别；主机与模具不会合并；包装备注不会随意拆出新品；同名不同编号不会自动合并；每一笔入库能追到任务与配置版本。

## 7. 需要业务/技术确定的边界

- 哪些配置变化意味着不能作为同一库存产品交付（盒高、盒材质、品牌、打码及其他选配等）？
- 机器入库按“带当前模具的一台整机”还是“主机与安装模具分别管理”？
- 木箱、额外模具、外配输送线等是否单独计价、入库与发货？

这些边界决定产品身份和套件关系；命名可以先试算，库存合并应等边界确认后再做。
