# 销售外采需求到采购执行

本阶段把销售订单的外采明细作为采购依据。业务员在销售订单的“配置外采需求”中填写产品名称、规格、型号、品牌、技术、验收、包装和交付要求。供应商、采购价格、采购审批和实际履约方式仍在采购订单处理。

销售订单草稿可保存未完成的外采配置；提交销售审批前必须完成配置。订单确认后，采购页的“待采购需求”按销售明细 ID 显示产品、规格、数量、交期和外采要求。销售订单明细可通过“办理采购”打开对应需求。

关联采购单采用一条销售明细对应一张有效采购单的现有关系。采购单的产品名称、规格、单位和数量按销售确认内容带入，前后端均禁止改写；同一采购单可以分批到货。如果以后要拆给多个供应商，需要先扩展一对多关联和剩余需求口径，不能通过填较小数量绕过。

到货入库型采购必须选择已有的库存产品档案，避免到货时才发现无产品身份、无法入账。供应商直发客户仍不经过本地库存。未有匹配档案的新外采产品，暂须先确认库存产品身份；本阶段不根据销售名称自动创建 SKU，也不把历史氚云台账作为生产库存层。

验证：外采需求前端录入与采购带入浏览器回归、自产配置回归、销售审批与采购到货/直发隔离真库契约、外采配置与采购需求一致性单测均通过。V348 在本地 Flyway 已执行。
