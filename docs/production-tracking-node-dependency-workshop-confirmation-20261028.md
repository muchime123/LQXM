> **为什么需要这张表**：系统当前把工序当作「一条直线」依次推算参考完成日。若钣金与模具实际是并行的，直线推算会把两个分支的工期**相加**，导致预测完成日系统性偏晚。要修正必须先把真实依赖关系确认下来。

## 填写说明

| 术语 | 含义 |
| --- | --- |
| **工序 / 节点** | 生产过程中的一个环节，如钣金、模具、组装 |
| **前置工序** | 必须**先完成**，本工序才能开始的工序 |
| **并行** | 两个工序可以同时做，互不等待 |
| **汇合** | 并行分支都往后走到的那个工序；汇合点决定"什么时候算都做完了" |
| **节点编码** | 系统内部标识，**请勿修改**；确认表用它对齐系统 |

**填写要求**

- 每张表按**机型**分别填（推杆机、转盘机可能不同）
- 能确定的填确定值；**不能确定的写"待确认"，不要猜**
- 本表只采集**事实**（实际怎么生产）；是否改系统由业务决策，不在本表定
