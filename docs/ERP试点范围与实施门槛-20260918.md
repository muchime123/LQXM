# ERP 试点范围与实施门槛

## 已确认范围

2026-09-18 用户明确选择：**浙江利强包装科技、温州仓、全自动气调机**。沿用已有 Q2 单一公司方向，不再重复要求选择公司。正式主数据 ID 需在启用前核实，名称不自动转换成身份绑定。

## 首个实施切片

先建设设备主档及配置关系、单据状态、库存过账和收付款分配的隔离沙箱。使用合成设备和明确数量的测试期初验证规则，不能将氚云温州仓快照自动迁为正式期初。

全自动气调机应重点表达设备型号、配置/图纸版本、配套模具、交付数量及售后追溯。已有 Q3 输入表明非标常来自换模具，建议设备型号与模具分开识别，并保存订单配置；这仍是设计建议，不应据此直接批量生成 SKU。

| 项目 | 当前处理 | 生产实施前条件 |
|---|---|---|
| 公司、仓库、商品组 | 已确认；沙箱据此命名范围 | 核实正式主档 ID 和归属 |
| 型号/模具/配置 | 各自独立概念，先设计样例 | 确定型号清单、何种配置改变库存身份 |
| 整机序列号 | 留设计决策，不默认关闭 | 设备售后是否逐台追溯；在哪一环节赋码 |
| 自制生产 | 未由本次范围回答明确纳入或排除 | 若上线覆盖自制，领退料、报工、检验、完工入库必须闭环 |
| 库存起点 | 沙箱使用合成期初 | 正式期初按盘点及未结事项签认 |
| 核销 | 同主体、同往来方、同币种 | 应收应付触发时点、预收预付和退款政策确认 |
| 成本 | 不用采购价假装制造成本 | 成本归集和在制品规则单独确认 |

## 当前实施顺序

1. 修正技术基线及验证误判，补资金并发/精度/回滚证据。
2. 针对全自动气调机整理型号、模具、配置、序列追溯及生产输入的最小样例，形成可评审对象关系。
3. 在隔离沙箱接入正式服务切片；权限、审计、幂等随切片一同验证，不能延期到上线前。
4. 真实接口跨身份测试、真实出库竞争、实际导入隔离和恢复演练完成后，再评估正式试运行。

当前授权覆盖建设与验证；不将业务尚未确认的型号粒度、序列号或核算政策固化到生产。
