| # | 事项 | 结论 | 定于 |
|---|---|---|---|
| 1 | 试点范围 | **浙江利强包装科技 + 温州仓 + 全自动气调机** | 09-18 |
| 2 | 设备/库存身份 | **型号（product_models） + 机型档位（product_machine_tiers）两级**；模具/选配/颜色/电机品牌 = 订单配置属性，**不进库存身份** | 09-18 |
| 3 | 单台序列号追溯 | **不追溯单台**。`lot_trace_status` 语义定为 `NOT_TRACKED`；`device_serials` 只出设计、不建表、不接线；机器按「型号+档位+数量」管理；将来转追溯改**新增流程**，不改出库单主表 | 09-18 |
| 4 | 自制生产纳入首批 | **纳入**，做「领料 → 报工 → 完工入库」三段 | 09-18 |
| 5 | 资金权威分层 | **双层权威**：事实权威当期 = 银行流水 Excel、**未来接银行 API 直连**；业务语义层 = 流水日记账（供应商/客户/报销人/是否开票），**永久保留**；业务关联方（销售出库收款、发票收款）不做独立资金记录 | 09-18 |
| 6 | 资金事件身份 | **独立 `fundId`**（系统生成）。`主体+账户+日期+金额+方向(+对方)` **降级为候选匹配条件**，不得作为唯一键或自动合并依据 | **09-21（修订）** |
| 7 | 资金来源幂等 | 银行来源 = `账户 account_no` + **银行稳定交易号**；无交易号 → **逐条保留 + 冲突复核**，不按金额日期合并 | **09-21 新增** |
| 8 | 资金信息分层 | **来源事实 / 人工标注 / 业务分配三层分表存储**；⚠️ API 同步**不得覆盖人工标注** | **09-21 新增** |
| 9 | 预收预付口径 | **不压成负应收**；多收/预付沉淀为**独立「未分配余额 / 预收待分配款」**，可核销到新单或原路退回。`未结金额 ≥ 0` 作为不变量保留 | **09-21（拍板）** |
| 10 | 成本范围 | 首批**不做金额账**：库存只有数量账，无金额账。⚠️ 页面**不得显示正式库存价值/毛利**（出库明细里的 `purchase_unit_price`/`source_profit` 是历史台账参考值，不是正式成本） | 09-18 |
| 11 | 技术架构 | ERP 独立 `erp` schema + 独立 Flyway（`erp_flyway_history`）；按单据族分表；库存用 `stock_event + stock_balance`；主数据三分复用；`@Version` 乐观锁 + 额度类 `FOR UPDATE`；复用现有 RBAC；统一 `ErpErrorCode` + `idem_request` + `row_change_log` | 09-17 |
| 12 | 请求幂等契约 | 请求键/动作/**操作人**三者必填，**无键不直通**；命中须同时比对 action 与 payload_hash；**重放不替代授权**；只覆盖同一 ERP 事务内可回滚的写入 | **09-21 收口** |
| 13 | 编码策略 | **非空编码终身占用**（`UNIQUE(code)`），停用不复用、可恢复原对象；草稿可无编码 | **09-21 收口** |
| 14 | 审计契约 | `row_change_log.operator_id` **必填**（姓名快照同记）；审计与业务**同事务**，双向回滚 | **09-21 收口** |
| 15 | 历史数据与 ERP 的关系 | **氚云数据 ≠ ERP 数据层**，只是参考样本 + 口径验证场；历史区→正式区唯一通道为 `external_id_map`，且仅 `CONFIRMED` 可引用 | 09-17 |
