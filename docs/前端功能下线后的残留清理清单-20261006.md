# 前端功能下线后的残留清理清单

> 2026-10-06 梳理。范围：2026-10-06 那批前端下线（`apps/erp/` 整目录 + 氚云侧「车间执行」「销售出库关联」页 + 产品库存页「配置产品审核」弹窗 + 一批生产抽屉/弹窗 + 24 个 e2e spec）。
> 方式：从 `router/index.ts` / `main.ts` / `App.vue` / `apps/index.ts` 出发做 import 图可达性分析，再逐层对外查（后端端点、数据库、权限码、文档、测试）。
> 结论均可用文中的 grep / SQL 复现。

## 一句话结论

删掉的是**承载**（页面、路由表、导航项），但支撑它们的**取数层、类型层、测试夹具、分组定义**，以及**一处活代码里的跳转**都还在。

共 6 类残留。其中**只有 A 类是运行期真故障**（点按钮跳 404）；其余是死代码与死定义 —— 不影响运行，但会持续制造「概念漂移」（同一概念两套口径的温床）。

**为什么静态检查没拦住**：`vue-tsc` 0 错、`vite build` 绿，因为文件级 import 都已解除；而路由跳转是**字符串**，类型系统管不到 —— 死链只在点击时暴露。所以 A 类不能靠编译发现。

## A. 死链（唯一运行期故障，必须处理）

**位置**：`frontend/src/components/h3/H3LedgerPanel.vue:161`

```vue
<el-button v-if="canExecute" link type="primary" size="small"
  @click="followUpRouter.push({ path: '/h3-production-execution', query: { sourceId: String(row.id) } })">
  查看执行
</el-button>
```

- 目标是氚云台账面板（出库/生产台账明细行）上的「查看执行」按钮
- `/h3-production-execution`（车间执行 · 氚云生产任务页）已于 2026-10-06 下线，路由已不存在
- 按钮显隐条件是 `canExecute`（第 855 行）：持有 `manufacturing.report` / `.report.override` / `.inspect` / `.followup` / `.read.self` / `.read.department` / `.read.all` **任一**权限即显示 —— 即所有生产类岗位都能看到
- 实际后果：有生产权限的用户点它 → 落到 `NotFoundView`（404 页），无报错提示

**三个选项**（需你选）：
1. 直接删按钮与相关权限判断（若「执行」这一视图整体放弃）
2. 改跳保留页（制程与工序管理 `/manufacturing-process-management` 或任务单产品与配置 `/manufacturing-task-configs`）
3. 保留按钮但禁用/加提示
