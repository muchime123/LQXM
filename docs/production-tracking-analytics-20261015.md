# 生产跟单交期分析口径（2026-10-16 更新）

## 现行口径

- 默认且唯一的分析范围是当前有效车间预计完成日期：`COALESCE(t.forecast_finish_date, p.expected_completion_date)`。起止日包含边界；延期调整后归入新预计日期区间。实际完工日在区间外不改变归属。没有车间预计日期的任务另计为待核实，不使用业务员要求日期兜底。
- 同账号可见范围及车间筛选与跟单列表一致。月份表及其下钻均按当前有效预计完成月份分组。统计状态取截至查询当天的最新记录，不是历史时点快照。
- 整单完工日优先取跟单员确认的入库节点完成日期。未确认时，只有**同一生产任务编号、同一产品名称**的采购入库明细累计数量达到计划数量，才取首次达到计划数的入库日期作为整单完工日；后续继续入库不推迟该日期。首次或部分入库不能直接确认整单完工；无法可靠匹配产品名称或计划数量缺失的记录留作未完工核实。人工确认优先于采购数据。
- 有效任务状态互斥：按期完工（整单完工日 ≤ 当前有效预计日）、逾期完工（整单完工日 > 当前有效预计日）、未完工（没有整单完工日）。未完工再分未到期、今天到期、已超过预计日期。原任务状态明确为取消/作废时单列并排除履约分母；停止本地跟单本身不排除任务。
- 应完成任务数＝按期完工＋逾期完工＋未完工；完工率＝已完工÷应完成；按期达成率＝按期完工÷应完成；已完工准交率＝按期完工÷已完工。未来日期范围的结果是进度快照，不作最终考核。
- 统计按任务单数，不按台数加权。采购数量按产品名称严格匹配；如源数据出现同名但不同规格/单位的行，仍需人工核实，不应把该分析当作数量台账。取消只按源任务状态的明确取消/作废值识别，不根据停止跟单推断。

## 旧版设计背景（2026-10-15，以下口径已停用）

## 入口与范围

生产跟单页 →「生产分析」抽屉。使用跟单列表同一可见范围：九月起自动纳入的氚云工单，以及已登记跟单或进度表覆盖的历史工单；跟单员仅看按车间分配给自己的任务，主管按权限看全部。可按日期起止和车间筛选，起止日均包含。日期口径有三种：

- **期间在制（默认）**：任务单提交/申请日期在截止日之前，且截至起始日尚未交付或停止。这样十月分析会包含九月提交、十月仍在生产或十月交付的延续工单。
- **按入库时间**：只包含入库日期落入范围的工单；入库日期以跟单员完成的「入库」节点为准，未登记时才使用关联采购首次入库日期。未入库工单不进入该范围。
- **按任务单提交时间**：只包含提交日期落入范围的工单，用于看新接任务。比期间在制少了此前提交的延续工单。

未选择日期时，期间在制及提交模式展示全部可见任务；入库模式只展示已有入库日期的任务。下钻清单沿用完全相同的日期口径。月份表依然按提交月份拆分筛选结果，用来识别上月结转。

## 指标定义

| 指标 | 分子 / 分母或计算 | 解读 |
| --- | --- | --- |
| 实际交付日 | 优先跟单员登记的「入库」节点日，未登记时采用关联采购首次入库日 | 报工完工只供对照；销售出库不作为生产交付 |
| 车间当前交期 | 跟单确认后的车间预计完成日 → 工单车间预计日 → 有效业务员要求日 | 业务员要求早于申请或提交日期时无效 |
| 车间承诺准交率 | 已交付且实际交付日 ≤ 车间当前交期 / 已交付且有车间当前交期 | 未交付、停止跟单和缺基准不进入分母 |
| 业务员要求达成率 | 已交付且实际交付日 ≤ 有效业务员要求日 / 已交付且有有效要求日 | 当前导入源值，不保证能恢复首次填写值 |
| 协商延后 | 跟单确认后的车间交期晚于工单原车间交期（无原车间交期时用有效业务员要求日） | 是改期动作，不等于实际逾期；同理提前单独统计 |
| 未交付逾期 | 未停止、未交付、交期早于今日 | 是当前风险，不进入已交付准交率分母 |
| 已交付逾期 | 实际交付日晚于车间当前交期 | 按 1–3 / 4–7 / 8 天及以上分布，并计算平均晚交天数 |
| 原因覆盖 | 协商延后看状态中的延期原因，缺时看最近协商核实；实际逾期看与当前交期及实际交付日快照一致的最近逾期核实 | 原因原文相同才合并，未记录显式计数 |

“车间承诺准交率”和“业务员要求达成率”应同时展示。只看当前车间交期，协商改期会抬高准交率；只看业务员要求，则无法体现后来双方接受的交期。两者分母不同，不能直接把差额解释为某一方责任。

## 阅读顺序

1. 看统计范围、已交付量、可比样本量和缺基准数，再看准交率。
2. 看未交付逾期及近三天到期，作为今日跟单优先级。
3. 看车间对比与提交月份趋势；近期月份未交付单多，已交付准交率可能有样本偏差。
4. 看协商延后与实际逾期的原因记录缺口，再看有据可查的原文分布。
5. 回到工单详情核对异常日期、入库与报工补录及时间核实记录。

分析卡片、车间/月份表中的数量与比率、协商改期和逾期原因可点击下钻。分析抽屉顶部会列出与当前日期、车间和所点指标完全一致的工单；点击任务号时，生产跟单详情作为上层抽屉打开，分析抽屉保留在下层。关闭详情后仍回到原指标与清单位置。下钻与汇总复用同一批可见工单、交付日、基准与原因快照判据，不用关键词近似搜索代替指标集合。

## 数据限制与后续改善

- 这是**按工单数**统计，不按台数或金额加权。多台分批入库的工单以首次入库作为当前交付日，不能据此判断整单数量已经全部交付。后续若要衡量数量准交，应增加工单数量与分批入库数量的归属核对。
- 采购入库和人工入库都可能补录或延后。页面单列两种来源覆盖数，实际现场完工日仍需跟单员核实。
- 延期原因自由文本只做原文汇总；风险类别来自结构化跟单字段，但填写率可能不足。正式的“原因占比”应待原因字典和必填规则稳定后发布。
- 当前只能看**现行交期**下的履约。若要计算“首次承诺准交率”“改期次数”“变更提前量”，需要从跟单历史可靠还原每一次交期快照并固定分析时点，不能用当前值反推。
- 停止跟单单列，不进入准交率；后续若要区分取消原因，可对停止原因建立结构化分类。
