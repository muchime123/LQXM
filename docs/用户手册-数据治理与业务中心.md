## 一、系统总览与角色入口

系统围绕"一笔业务"的完整生命周期组织：

```
数据导入 → 匹配确认 → 统一业务单 → 生产执行 → 销售出库 → 正式收款 → 费用归集 → 利润核算 → 提成结算
```

### 各角色默认入口

| 角色 | 推荐入口 | 最需要关注的内容 |
|------|----------|------------------|
| 业务员 | 我的工作台 | 我的业务、待回款、利润、预计提成 |
| 生产人员 | 生产执行 | 今天要做、逾期、待入库 |
| 财务人员 | 收款核销 | 未分配收款、异常分配、待确认回款 |
| 管理人员 | 经营看板 | 销售、回款、利润、异常 |
| 系统管理员 | 数据治理 | 导入、匹配、审计、规则 |

> **核心原则**：日常业务操作不需要进入"数据治理"页面。数据治理只负责管理氚云源数据质量。

## 二、我的工作台

**入口**：工作台 → 我的工作台

### 页面内容

#### 个人汇总卡

展示当前业务员（或选中业务员）的汇总数据：

| 指标 | 含义 |
|------|------|
| 待跟进询盘 | 未关闭的询盘数量 |
| 生产中 | 正在生产中的业务单数（含逾期提示） |
| 已生产完待入库 | 生产完成但尚未入库 |
| 本月出库 | 本月已确认的出库单数 |
| 本月收款 | 本月正式到账的收款笔数 |
| 本月销售额 | 本月出库金额合计 |
| 本月已收（正式到账） | 本月 DIRECT 正式回款金额 |
| 未回款合计 | 所有未结清出库的应收余额 |

#### 业务卡片

每张卡片代表一笔业务，显示：
- 客户名称、业务号、业务类型
- 当前阶段（生产中 / 已出库 / 部分回款 / 已结清）
- 应收、正式到账、未回款
- 核算利润、预计提成
- **下一步操作**按钮（如"查看回款""联系客户""核算利润"等，根据当前阶段动态变化）

### 操作方式

1. 顶部可按业务员筛选（管理员可见全部业务员）
2. 可按生命周期阶段筛选
3. 点击业务卡片打开完整业务详情
4. 点击「下一步操作」按钮直接跳转到对应页面

## 三、业务档案

**入口**：业务中心 → 业务档案

### 页面内容

#### 搜索与筛选

- 关键词搜索：业务号 / 客户 / 业务员
- 生命周期筛选：全部 / 询盘中 / 生产中 / 待出库 / 已出库 / 部分回款 / 已结清
- 客户筛选（从客户档案带入）

#### 列表字段

| 列 | 含义 |
|----|------|
| 业务号 | 系统自动生成的唯一编号 |
| 客户 | 客户名称快照 |
| 业务员 | 销售员姓名 |
| 类型 | 业务类型 |
| 当前阶段 | 生命周期状态 |
| 生产/出库 | 关联的生产任务数和出库单数 |
| 销售额 | 出库单金额合计 |
| 利润 | 核算利润（已核算则显示，否则显示"等待核算"） |
| 操作 | 查看详情、下一步操作 |

### 业务详情

点击任意行进入业务详情页（独立路由 `/business/{id}`，可分享链接、可前进后退）。

详情页包含 5 个 Tab：

| Tab | 内容 |
|-----|------|
| 概览摘要 | 生命周期时间线 + 最近动态 |
| 执行进度 | 生产工单表 + 销售出库表 + 产品明细表 |
| 收款结算 | 应收/已回/未回 + 回款记录表 |
| 利润提成 | 利润快照 + 费用归集 + 提成信息 |
| 数据追溯 | 数据来源、关联关系、匹配历史 |

顶部固定区域显示：客户、业务员、业务类型、当前阶段、应收/到账/未回款、利润/提成、当前异常和推荐下一步。

## 四、销售出库

**入口**：业务中心 → 销售出库

### 页面内容

#### 统计卡（可点击筛选）

| 指标 | 含义 | 点击效果 |
|------|------|----------|
| 出库总数 | 全部出库单 | 清除筛选 |
| 已结清 | 完全回款的出库 | 筛选"已结清" |
| 部分回款 | 部分回款 | 筛选"部分回款" |
| 未回款 | 未收到任何回款 | 筛选"未回款" |
| 应收总额 | 所有出库金额 | — |
| 正式到账（DIRECT） | 钉钉收款的正式分配金额 | — |
| 快照登记（SNAPSHOT） | 氚云导入的快照金额 | — |
| 未回款 | 应收 - 已到账 | — |
| 本月出库 | 本月新增出库数 | — |

> **重要**：金额分两种口径——"正式到账"是钉钉收款核销的真实金额，"快照登记"是氚云导入的历史记录。以"正式到账"为准。

#### 象限筛选卡

页面下方有四个象限卡，点击可快速筛选：
- 正式核销（有正式回款）
- 仅快照登记（只有氚云快照）
- 部分回款
- 已结清

#### 列表与详情

- 支持按关键词、回款状态、工作流阶段筛选
- 点击行打开出库详情（含明细行 + 分配记录）
- 详情中可"查看相关收款"，不直接进行核销操作

## 五、收款核销

**入口**：财务结算 → 收款核销

### 核心操作流程（三栏式分配）

```
左侧：选收款单 → 中间：勾选出库 → 右侧：确认分配
```

#### 第一步：选择收款单（左栏）

- 收款单列表显示所有有效收款（已生效/已确认）
- 支持按单号/客户/业务员搜索
- 可筛选单据类型（单订单收款 / 多订单结清）
- 可筛选分配状态（未分配 / 部分分配 / 已全部分配）
- 选中一张收款单后，中间栏自动加载推荐出库

#### 第二步：勾选出库（中栏）

选中收款单后，中间栏显示：
- 系统推荐的出库单（按客户匹配、金额相近度排序）
- 每张出库的：出库号、客户、应收金额、未回款金额
- 勾选要分配的出库单

#### 第三步：确认分配（右栏）

- 输入或确认分配金额（默认填入出库的未回款金额）
- 点击「保存草稿」暂存（不改变实际数据）
- 点击「确认核销」正式写入分配记录
- 核销后出库的回款状态自动更新

### 统计卡

| 指标 | 含义 |
|------|------|
| 收款单总数 | 全部有效收款单 |
| 已全部分配 | 金额已 100% 分配完 |
| 部分分配 | 有分配但未全部分配 |
| 未分配 | 尚未分配到任何出库 |
| 收款总额 | 所有收款金额合计 |
| 已分配 | 已分配到出库的金额 |
| 可分配余额 | 尚未分配的余额 |

### 高级维护工具

> 仅管理员可见，用于历史数据修复，日常核销不需要使用。

- **去重内嵌收款**：清理重复导入的收款记录
- **修正金额映射**：修复金额字段映射错误
- **补齐出库关联**：补全缺失的出库 ID 关联

## 六、费用归集

**入口**：经营核算 → 费用管理

### 页面内容

#### 统计卡

| 指标 | 含义 |
|------|------|
| 累计有效报销单 | 排除拒绝/撤销/终止的报销单总数 |
| 本月核定报销额 | 钉钉审批通过的金额 |
| 待员工身份映射 | 提单人尚未映射到员工的报销单 |
| 待归集 | 已审批但金额未分配完的报销单 |
| 对公付款待核对 | 已通过审批、尚未核对入账的金额 |

#### 两个 Tab

**报销单 Tab**：
- 搜索：单号 / 标题 / 提单人 / 备注
- 筛选：审批状态、费用类别
- 列表展示每张报销单的归集进度
- 支持批量智能归集（勾选多张 → 点击"批量智能归集"）
- 点击行打开详情 Drawer

**对公付款 Tab**：
- 展示待核对的对公付款记录
- 支持手动核对入账

#### 费用归集操作

1. 选中一张报销单 → 点击「归集」
2. 在弹出的归集面板中选择目标（业务单/部门/公司）
3. 输入分配金额（支持一条费用分配到多个目标）
4. 确认后费用状态变为"已归集"
5. 归集后的费用会自动参与利润核算

## 七、利润核算

**入口**：经营核算 → 利润核算

### 前置条件状态链

页面顶部显示核算前置条件链：

```
产品已匹配 → 成本已确认 → 费用已归集 → 利润已核算 → 正式回款达标 → 提成可结算
```

- 有异常的步骤显示橙色 `!` 图标 + 红色数字
- 无异常的步骤显示绿色 `✓`
- 点击任意步骤跳转到对应页面处理

### 异常快捷筛选

状态链下方提供异常筛选按钮：
- **无产品成本**：有出库但成本为 0 的业务
- **有未归集费用**：已审批但未归集的报销单关联的业务
- **利润未核算**：尚未核算利润的业务

点击后列表自动过滤，再次点击取消。

### 列表字段

| 列 | 含义 |
|----|------|
| 业务号 | 关联的业务单 |
| 客户 | 客户名称 |
| 销售收入 | 出库金额合计 |
| 产品成本 | 出库采购成本 |
| 毛利 | 销售收入 - 产品成本 |
| 已归集费用 | 分配到该业务的费用合计 |
| 核算利润 | 毛利 - 费用 - 调整项 |
| 状态 | PENDING / CALCULATED / ERROR |
| 诊断 | 自动诊断标签（如"成本待确认""费用为零"） |
| 操作 | 查看明细、重算 |

### 利润明细

点击行打开利润明细 Drawer：
- 当前快照：销售收入、成本、费用、调整项、核算利润
- 已归集费用列表
- 其他成本调整
- 核算历史（版本记录）

### 批量核算

1. 点击「批量核算」→ 选择范围（日期/业务员/阶段）
2. 预览将要核算的业务列表
3. 确认后执行批量核算
4. 完成后自动刷新列表

## 八、提成结算

**入口**：经营核算 → 提成管理

### 前置条件状态链

与利润页相同的状态链，当前步骤标记为"提成可结算"。

### 快速筛选

- **员工未映射**：提成人未映射到系统员工
- **无适用规则**：没有匹配的提成规则
- **可结算**：满足结算条件的提成
- **已结算**：已完成的结算

### 三个 Tab

**提成明细 Tab**：
- 列表展示每笔业务的提成信息
- 字段：业务号、客户、业务员、预计提成、可结算提成、回款进度、状态
- 状态：UNMAPPED / PENDING / AVAILABLE / SETTLED
- 点击「结算」对可结算的提成发起结算

**规则管理 Tab**：
- 配置提成规则（按员工/部门/产品线）
- 设置提成比例和适用条件
- 规则优先级排序

**结算单 Tab**：
- 查看历史结算单
- 确认发放 / 作废结算单

### 提成结算流程

1. 确认业务已有利润核算
2. 确认正式回款达到结算门槛
3. 在提成明细中找到状态为"可结算"的记录
4. 点击「结算」→ 生成结算单
5. 在结算单 Tab 中确认发放

## 九、氚云导入中心

**入口**：数据治理 → 氚云导入中心

> **定位**：这是系统管理员的页面，负责将氚云导出的 Excel 导入系统。日常业务不需要使用。

### 导入数据类型

| 类型 | 图标 | 说明 | 识别依据 |
|------|------|------|----------|
| 生产任务 | 产 | 工单主表与零部件制程 | 生产工单流水号 |
| 销售出库 | 出 | 出库主单与产品明细 | 销售出库编号 |

> 说明：收款记录、多订单结清两类数据已停止导入（氚云侧不再同步），目前仅维护生产任务与销售出库。

### 导入操作流程

1. 在导入卡片中点击「选择 Excel」
2. 弹出导入预览对话框
3. 选择文件后点击「开始解析」
4. 系统解析 Excel 并显示预览（新增/更新/无变化数量）
5. 确认无误后点击「确认导入」
6. 导入完成后自动进行后台检查（出库快照刷新等）
7. 结果面板提示下一步操作（查看销售出库 / 查看核销记录等）

### 导入批次列表

- 展示所有历史导入批次
- 可按数据类型筛选
- 失败批次可下载错误报告或重新处理
- 显示每批次的：总数/新增/更新/无变化/完成时间

### 导入后建议流程

```
导入完成 → 查看销售出库 → 财务收款核销
```

## 十、完整业务流程示例

### 示例：一笔业务从导入到提成结算

#### 第 1 步：导入氚云数据（系统管理员）

1. 进入「数据治理 → 氚云导入中心」
2. 依次导入生产任务、销售出库两类 Excel（收款记录、多订单结清已停止导入）
3. 每次导入后确认预览无误，点击「确认导入」
4. 导入完成后查看销售出库与核销记录

#### 第 2 步：业务员日常跟进

1. 进入「我的工作台」
2. 查看个人汇总卡和业务卡片
3. 点击「下一步操作」处理待办
4. 对已出库的业务催收回款

#### 第 3 步：财务核销收款

1. 进入「收款核销」
2. 在左栏选中未分配的收款单
3. 在中栏勾选对应的出库单
4. 在右栏确认分配金额 → 点击「确认核销」

#### 第 4 步：归集费用（财务）

1. 进入「费用管理」
2. 选中已审批的报销单 → 点击「归集」
3. 选择目标业务单，输入分配金额
4. 确认归集

#### 第 5 步：核算利润（管理员）

1. 进入「利润核算」
2. 查看前置条件状态链有无异常
3. 点击「批量核算」→ 选择范围 → 预览 → 执行
4. 确认所有业务利润已核算

#### 第 6 步：结算提成（管理员）

1. 进入「提成管理」
2. 查看前置条件状态链
3. 在提成明细中筛选「可结算」
4. 选中后点击「结算」
5. 在结算单 Tab 中确认发放

## 附录：常见问题

### Q: 正式到账和快照登记有什么区别？

**正式到账（DIRECT）**：通过收款核销页面，将钉钉收款正式分配到出库单的金额。这是真实回款。

**快照登记（SNAPSHOT）**：氚云导入的收款记录中的金额，只是历史快照，不一定经过核销。以"正式到账"为准。

### Q: 为什么我的业务利润显示"等待核算"？

利润核算有前置条件：
1. 产品已匹配（出库有关联的产品成本）
2. 成本已确认（出库采购金额 > 0）
3. 费用已归集（已审批的报销单已分配）

在利润核算页面顶部的状态链可以查看哪个步骤有异常，点击跳转处理。

### Q: 收款核销时"保存草稿"和"确认核销"有什么区别？

- **保存草稿**：暂存分配方案，不改变实际数据，可以反复修改
- **确认核销**：正式写入分配记录，出库回款状态立即更新

### Q: 业务详情页面可以分享链接吗？

可以。业务详情是独立路由 `/business/{id}`，可以直接复制浏览器地址栏的 URL 分享给同事。

### Q: 批量操作时选中的数据跨页有效吗？

不支持。批量操作只对当前页选中的数据有效。如需处理更多数据，请使用「批量核算」「批量智能归集」等按条件批量处理的功能。
