## 对现行设计的影响

1. **编号命中不足以采信产品身份。** 55 行同编号不同名，当前页面会按编号取产品信息采购价；正库存 3 行尤其可能计错金额。
2. **名称匹配也需歧义控制。** 360 行同名多候选，不可直接取第一条；同名可能对应不同规格、单位或采购价。
3. **缺产品信息多数有候选。** 307 行错码候选分析里，268 行名称＋规格＋单位唯一吻合，但仍需氚云源单确认后改号。零库存 296 行可排在有库存问题之后。
4. **缺价不能一概归为错码。** 排除费用项后的正库存缺价 17 行，未发现同名的其他编号候选。需核对自产/占位/真实缺价。

## 建议的匹配规则

先保留两份原始台账，不批量重写氚云编号。产品库存展示层可按下列顺序解析，并把命中方法及歧义显式展示：

1. 编号一致且名称一致，再核对规格、单位；均兼容时认定为直接匹配。
2. 编号缺失或同编号名称冲突时，查名称＋规格＋单位的**唯一**候选；只给“建议关联”，待人工确认后再用于正式计价。
3. 规格缺失时，允许名称＋单位的唯一候选作为较弱建议；同名多个候选、单位冲突、名称空白均挂待核，不自动选择。
4. 未确认身份或价格单位不一致的正库存行，库存金额显示“待核”，不以错误采购价或 0 元代替。

这是一份设计核查结论，尚未更改产品库存查询逻辑或氚云源记录。
