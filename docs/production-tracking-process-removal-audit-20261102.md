# 生产跟单制程管理撤除后的遗留清理

## 已清理

- 制程管理路由、导航、页面；产品制程版本组件；本单制程调整弹窗。
- 节点字典与默认流程的前后端管理 API，以及已无消费者的只读 API。
- 节点管理服务中的在线增删改、排序、影响预览代码；保留启动加载代码维护的默认流程定义。
- 产品制程版本创建、发布、样本和本单修订接口与对应服务方法、过时测试。
- 氚云生产任务首次导入时自动建跟单制程快照的调用及无用依赖。
- 生产参考工期的节点校验改回当前车间默认跟单节点，不再依赖撤除的全局字典表。
- V437 清理无任务引用的气动转盘封口机试验版本；V438 清理无任务引用的试验“画图”绑定及全局字典表。迁移只会在应用启动执行，提交代码不等于实库已执行。

## 保留的兼容数据与代码

- 38 张 `LEGACY` 任务快照及节点记录：现行跟单详情、完成率、结案和分析仍会读取。保留只读快照接口。
- `production_tracking_process_snapshots` 等旧快照表及相关读取 SQL：直接删除会改变已有任务节点分母和完成判断。
- 产品模板相关表目前作为历史结构保留；V437 后正式系统无创建或发布入口，且试验模板无任务引用。清理表结构需要另行迁移处理快照外键，并复核所有部署环境中是否存在模板引用。
- `production_tracking_stage_defs`：节点及车间默认流程由代码迁移维护，启动时加载供列表、详情和历史跟单使用。

本次实库只读核查：产品模板 2 个（均为气动转盘封口机试验版本、0 张任务引用）、快照 38 张（均为 `LEGACY`）、字典独有节点 0 个、非默认绑定仅 `SEALER/DRAWING`。这些是迁移执行前的核查结果。
