# 产品基础目录与配置命名设计

日期：2026-09-27。首个试点：浙江利强包装科技／温州仓／全自动气调机。

本设计依据当前生产任务、任务配置、产品信息及仓库库存归纳，承接《生产任务配置驱动产品身份与出入库实施契约-20260924》。这是建设方案，不代表字段、接口与自动命名能力已经上线。氚云记录保留来源原文，作为参考样本与口径验证场。

## 1. 范围与原则

先处理“选什么基础产品、怎么配置、生成什么入库名、如何确认库存产品身份”。不要求清洗完所有历史数据，也不依靠名称相同自动合并产品。

继续使用现有“任务单产品与配置”维护入口，以及销售订单调用的同一生产任务单配置抽屉。不新增第二套机器配置录入页面，不要求氚云导入任务另建一张正式制造工单。

三个层次分别保存：

| 层次 | 示例 | 用途 |
| --- | --- | --- |
| 基础产品 | LQ750全自动推杆 | 限定配置字段、可选项、制程与命名模板 |
| 订单/任务配置快照 | 186×136、1出4、简单封口、三相380V等 | 保存客户要求和执行版本；尚未确认实物时也可存在 |
| 库存产品身份 | 唯一产品ID和编号＋已确认完整配置 | 按同一种可互换实物记库存与选货 |

基础名、显示名、配置指纹都不作为业务外键。业务引用产品ID，任务和订单明细使用各自ID追溯。

| LQ310T台式黑白机 | 机器 | 保留基础名，补机型配置规则 |
| LQ330L立式贴体机 | 机器 | 使用贴体机配置规则 |
| LQ350T台式贴体机 | 机器 | 使用贴体机配置规则 |

## 3. 配置字段与选配分组

### 3.1 机器字段

- 基础产品ID、产品类型、配置规则版本。
- 盒形：方形、圆形、异形。方形录长宽，圆形录直径；异形录说明及图纸引用。
- 盒高、盒材质、模具排列/出数：结构化保存。盒材质不能解释成机器机壳材质。
- 电气：相数、电压、插头；品牌/标识要求。
- 产品适用的技术选配、独立附件、交付包装。
- 设计图纸/技术附件、其他要求及其确认情况。

沿用现有必填要求作为首版起点；不同机型是否适用盒材质、盒高等字段，由机型规则明确。字段不适用时标记“不适用”，不能用空值冒充默认规格。

LQ750D等多模具产品支持多组模具需求，每组有尺寸、排列、用途与图纸版本；不得把多个尺寸塞进一个boxSize字符串。首阶段尚未支持多组的入口应明确提示待技术确认，不能静默截取第一组。

### 3.2 当前全自动产线选配的建议分组

| 分组 | 当前选项示例 | 规则 |
| --- | --- | --- |
| 封口/工艺模式 | 简单封口、气调式、气流式 | 建议按模式选择；是否互斥由技术确认后启用规则 |
| 进出盒与输送 | 自动落盒、自动出盒、自动进盒(7字型/直线型)、外配输送台 | 内置功能与独立外配设备区分 |
| 膜处理 | 自动卷膜、自动切膜 | 按基础机型限定适用项 |
| 灌装 | 气动活塞泵、电动缸活塞泵、直流式、磁力泵、量杯式 | 建议单选；多站系统应配置站位，不直接判错 |
| 打码 | 字粒、色带、油墨喷码、激光 | 允许哪些组合由机型规则决定 |
| 模具/结构 | 易撕口、打针孔、铜烫板、普通烫板、加宽、加长双排封口、出盒二/三/四变一 | 区分基础特征、模具结构和设备结构；不能所有机型共用一串选项 |
| 独立附件/设备 | 贴标机、称重贴标机、金属检测、外配输送台 | 判断是否独立产出/采购、计价和交付 |
| 包装 | 木箱、出口木箱 | 默认作为包装要求；特殊保管或成套库存规则另行定义 |
| 待技术解释 | 圆盘机、震动等 | 先保存原始选项，确认适用机型与含义后再参与身份规则 |

以上是设计分组，不是已确认的兼容矩阵。每个配置项具有稳定代码、显示名称、分组、排序、适用基础产品、是否参与产品身份及规则确认状态。改显示名称不改变代码。

## 4. 名称与规格生成

机器完整显示名建议：

`基础产品名｜盒形尺寸｜模具排列｜关键技术选配｜电气/插头/品牌`

例（规则说明）：`LQ750全自动推杆｜方盒186×136mm｜1出4｜简单封口+特氟龙+出盒4变1｜三相380V/国标/利强品牌`。

完整规格包括盒高、盒材质、全部技术选配、图纸版本及其他已确认实物要求；与显示名同源生成。短名称可以少展示字段，但库存选货必须同时显示编号和完整规格。

模具显示名：`适配机型｜模具类型｜盒形尺寸｜模具排列｜图纸版本`。配件显示名：`具体配件名称｜型号规格｜必要的适配机型`。不以“模具”“配件”泛称直接建立可售产品。

规则由后端统一生成，前端预览使用同一接口。保存时后端重新生成，不能信任前端提交的拼接名称。保存命名规则版本与名称快照；主数据改名不追改历史单据。

规范化要求：

1. 尺寸统一mm；方形长为较大边，录反提示纠正，不能静默交换。圆形展示Φ，数值单独保存。
2. 一出数与排列结构分开保存；2出1与1出2不未经确认互换。
3. 选配以稳定代码排序、去重；顺序不同不产生另一种产品。互斥项按已确认规则校验。
4. 单项/三项电压等明显文字别名仅在有依据时规范化，并保存来源原文。
5. 2014、2617*8、38*27等历史表达缺少单位或含义时进入待核对；不能猜测换算。
6. 客户、业务员、仓库、数量、交期、任务号不进入产品名或产品身份。

## 5. 产品身份确认与复用

首版采用保守规则：基础产品ID＋全部已确认结构化实物规格＋技术选配代码＋影响实物的图纸版本生成规范化配置。盒高、盒材质等暂按区分处理，技术确认不会影响互换后才能从相应机型规则中排除。

木箱等纯交付包装保存到需求/包装快照，默认不改变机器身份。存在特殊包装计量、成套销售或独立库存管理时，先定义组合关系再执行。

| 情况 | 处理 |
| --- | --- |
| 完整配置一致、规则已确认 | 生成候选复用结果；验收确认实际一致后引用已有产品ID |
| 电压、插头、品牌、关键技术选配不同 | 分开产品身份 |
| 仅客户、任务、交期不同 | 可复用产品身份，来源任务分别追溯 |
| 只有名称/尺寸/出数相同 | 不能证明同款，不自动复用 |
| 配置缺失、异形图纸未确定、说明可能影响实物 | 待确认，不参与自动复用 |
| 历史同编号不同名，或一个名称有多个编号 | 显示差异证据，人工核对映射，不自动改名或合并库存 |

通过已确认规则生成指纹仅用于候选查找和防止重复建档；命中后还要比较完整规范化配置，业务仍引用产品ID。不同规则版本即使描述相同，也不自动生成一份新的同款库存；应查询旧身份并执行规则升级/映射确认。

产品身份确认发生在产出及入库前，不能把“名称预览成功”当成“库存产品已确认”。订单配置可以先于产品身份存在。

## 6. 产出清单与业务衔接

1. 销售自产需求：同一任务配置抽屉录入并预览，保存到订单明细；销售确认后冻结需求版本。
2. 独立生产任务：展会、展厅、备货等沿用同一配置规则，可以没有销售订单。
3. 车间接单：引用需求快照，产品决定制程；不重新填写配置。需求需要调整时先发起变更，不能偷偷修改已确认订单。
4. 产出清单：主机、额外模具、独立附件分行，明确计量单位与配置。安装在主机内的组成件不得在同一实物上重复计入可售余额。
5. 检验入库：查看实际配置与预计入库名，确认身份及合格产出后一次办理入库；配置不符先返工或变更确认，不靠自由改名继续入库。
6. 库存与出库：选择产品ID，显示统一名称与完整规格；保留任务、入库批次、订单行关联。名称一致不代表可以替代客户需求。
7. 氚云任务：使用导入任务及其配置候选，缺字段进入映射确认，不另造正式任务；已有来源入库与本地办理须防重复。

## 7. 数据与接口落点

在现有主数据/库存链上增量建设，避免再起一套余额表。

| 当前对象 | 建议改造 |
| --- | --- |
| manufacturing_task_config_items | 基础产品与选配记录补稳定代码、类型、分组、排序；旧中文名称保留为显示标签/来源信息 |
| 产品与产线适用关系 | 首版沿用workshop_id；跨产线复用后再建立显式关联，不自动迁移合并 |
| 新配置规则表 | 基础产品ID、版本、字段规则、选配适用与兼容规则、发布状态、发布时间；草稿和已发布分开 |
| sales order line / manufacturing task | 保存基础产品ID、规则版本、完整配置快照、预览名；已确认数据保留版本 |
| manufacturing_order_outputs | 保存产出类型、基础产品ID、规范化配置、确认状态、产品ID及名称规格快照 |
| sales_products | 承接确认后的库存身份；补基础产品ID、身份规则版本、规范化配置、指纹和来源；保留现有ID/编号及canonical链 |
| 历史名称映射 | 保存来源表＋来源行ID＋原名/编号＋确认产品ID＋确认人/时间；同名不同编号分别核对 |
| product_inventory_balances / transactions | 继续使用现有产品身份和单位口径；不因显示名变化直接改库存归属 |

拟新增能力：

- 查询基础产品的已发布配置规则。
- 预览配置：返回校验问题、完整名、规格及待确认字段，不写产品或库存。
- 查找产品身份候选：返回匹配依据与配置差异，不自动改关联。
- 确认产出产品身份：有权限的人员确认并留审计；无候选时按完整配置建档。

具体URL与迁移版本号在编码时按当前仓库最大版本分配。供应商、采购价、销售价分别留在采购/销售事实中，不进入本次命名身份规则。

## 8. 页面设计

“任务单产品与配置”：产线→基础产品→字段与选配规则。基础名、产品类型、制程、模板和规则版本在同一处维护；增加草稿预览与发布，不在生产填写页编规则。

现有任务抽屉：先产线与产品，按类型展示字段；选配按组出现；底部实时展示预计入库名、完整规格和需要技术确认的项。机器、模具、配件共用抽屉外壳，各用适合的字段。

检验入库：主机和额外产出逐行展示配置、预计名、产品编号和确认状态。操作是“确认产品身份/查看差异”，避免只按相似名字盲选产品。

库存选货：名称、编号、关键规格、单位、可用量并列；查看详情可追到配置和产出任务。未确认映射的历史样本不自动作为新品可售身份。

## 9. 建设顺序与验收

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 1 基础目录 | 11个机器基础产品及模具/配件入口，稳定代码和选配分组 | 改标签不改变ID；LQ450跨产线不误归类 |
| 2 命名预览 | 后端统一校验/命名，现有抽屉显示预计名与规格 | 相同配置不同勾选顺序名称一致；缺字段不给误导性的完整结果 |
| 3 身份确认 | 产出配置候选、人工确认、规范化建档与复用 | 相同确认配置跨任务复用ID；不同电压/选配分开；泛称模具不能入库 |
| 4 入库出库 | 现有库存链按确认身份办理，主机与额外模具分行 | 来源可追溯、数量不重复、过账/冲正幂等 |
| 5 历史映射 | 逐项确认样本与存量映射 | 同编号异名不自动合并，不要求全历史清洗完成 |

首阶段只完成目录、规则与名称预览，不改历史产品编号，不重分现有库存余额。建议先验证LQ750全自动推杆、LQ310T台式黑白机、LQ750D全自动多模具三类真实样本；该建议按机型覆盖选择，不等于已确认技术兼容规则。

待技术确认集中为：各机型必填/适用字段、关键选配兼容关系、盒高与盒材质的互换判定、模具图纸版本及主机/模具分账方式、独立附件与包装的库存处理。未确认部分可展示和留痕，不能据此自动合并产品。
