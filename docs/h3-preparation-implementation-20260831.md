# 迁移准备模块：本阶段实现与使用

日期：2026-08-31。入口：系统管理 → 迁移准备（`/h3-preparation`），沿用 `integration.h3` 权限。所有新增接口都要求该权限，不开放匿名读取或写入。

## 本阶段边界

实现产品来源映射、库存期初候选核查、出库客户只读统计。未实现正式期初过账、库存总账、日常收发、采购/开票导入，也不恢复历史收款分配或生产联动。准备仓库名称表不是正式仓库主表。

新增V216迁移仅创建三张独立准备表：批次、来源行与映射、已确认候选仓库名称。不更新产品、客户、出库、收款、库存或核算表；不得将旧库存事件再累加到未来期初。

## 使用步骤

1. 部署含V216的后端版本与新前端；Flyway正常启动时创建准备表。尚未部署的新接口不能由旧后端提供。本轮没有重启在用业务服务，也没有对业务库执行V216。
2. 打开迁移准备，选择“产品信息”，上传本次产品Excel。仅保存来源候选，原产品档案不变。
3. 选择产品批次，搜索源产品，点击映射；选择现有机器规格、包材规格或模具，勾选交易单位确认。没有合适档案的行保持待核，不按名称自动新建产品。
4. 选择“仓库明细”，指定其实际库存快照时间和第2步产品批次，上传库存Excel。不根据文件名推断时点。
5. 核对来源仓库名称与实际三条仓库资料；逐一登记名称后刷新检查。
6. 按“存在待核项”筛选，查看问题统计与来源行。零库存保留；负库存、歧义、缺失信息不能自动归零或绕过。
7. 本阶段“通过当前检查”仅表示通过已实现的技术检查，不表示已完成业务盘点、期初批准或库存过账。正式切换需要独立阶段实现。

## 已实现的保护

- 仅接受xlsx，上传上限25MB、单文件100000条明细；SAX逐行解析Sheet1，不执行公式、不访问附件或外部链接。
- 产品以源子表记录ID存档，不把父记录合并空白当作产品值。保存源行号、列坐标、原字段编码、原始值。
- 库存数量读取原始XML数值，避免Excel显示格式把小负数显示成零。候选以精确十进制字符串存储；超出正式库存拟支持精度的值保留并标记待核，不静默四舍五入。
- 文件SHA256加批次类型、快照时间和产品批次构成幂等键；唯一约束和行锁隔离并发重复上传。解析或写入失败时整批回滚。
- 新文件保存新批次，不覆盖历史来源；新产品批次不无条件继承旧映射。
- 映射校验目标档案与所属主档案均未软删除；确认单位必须等于来源单位，本阶段不做单位转换。相同目标存在多个确认交易单位时拦截。
- 映射写入有版本检查，避免并发覆盖，支持清除映射，记录审计日志。
- 库存检查包括缺少/重复源ID、缺少产品编号/名称/单位、产品编号未命中或歧义、产品来源ID重复、未映射/目标失效、单位不一致、名称/规格不一致、未确认仓库、非已生效状态、负库存、重复来源余额、多个源记录映射同一目标余额。
- 库存预览针对绑定的产品批次重新计算，不因之前曾显示通过就跳过当前检查。
- 页面切换批次和异步搜索有请求顺序保护，避免较慢旧请求覆盖当前结果。

## 验证方式

最终验证：12项后端专项测试全部通过（包含本次实际Excel和隔离MySQL），前端类型检查与定向ESLint通过，隔离页面交互测试通过并完成桌面/窄屏截图检查。修复了Excel显示格式掩盖小负数以及MySQL并发上传后快照读看不到新批次的问题。该验证不等于在业务环境完成端到端部署验收。

- `H3PreparationParserTest`：负数/零/非法值、缺失ID、重复行保留、双表头、产品子行、错误表头、精度保护；可选实际文件验证产品15131条、库存16204条、负库存38条。
- `H3PreparationServiceTest`：库存有效状态、负数、单位/仓库相关前置检查、缺少快照上下文不写库、控制器权限声明。
- `H3PreparationMysqlTest`：可选隔离MySQL测试。创建随机命名测试库，仅执行V216与最小测试档案；测试重复上传、映射、版本冲突、目标余额冲突、单位冲突、并发幂等、目标软删除失效和失败回滚；结束后仅删除本测试创建的库。不启动业务应用，不迁移业务库。
- 前端：类型检查、定向ESLint、Vite构建；隔离界面夹具使用本地模拟响应，不发送业务API请求。检查批次选择、目标与单位必须同时确认、保存映射、来源查看及桌面/窄屏展示。

## 已知限制

- 当前显示最近100个准备批次；预览对单批数据做线性核查，适配本次约1.5万/1.6万行规模，并非百万行异步导入平台。
- 暂无批量自动确认映射；产品名称相似不作为可靠自动匹配证据。没有交易规格档案的产品保留待核。
- 仓库名称按文本确认，不合并别名，不代表正式仓库权限与配置已完成。
- 只提供客户缺口统计，尚未提供88条缺失客户的人工修复界面。
- 采购、经销商、开票文件不在本次新增上传类型之内，避免未经核实即扩大写库范围。
