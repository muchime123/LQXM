# 官网公司资料独立来源切换记录（2026-11-02）

## 范围与结果

本轮仅切换官网公开公司介绍、发展历程和官方社交链接的数据来源。产品、资质、知识产权等模块沿用各自的独立切换进度；内部公司档案仍供内部业务使用。公开公司接口现在默认读取官网专属表，保留 `APP_WEBSITE_COMPANY_SOURCE=legacy` 作为显式回退配置。官网内容不会随内部档案编辑自动变化。

## 数据准备与核对

- 复制官网现用静态 Logo 到官网媒体目录，登记 `website_media_assets.id=147`，绑定 `website_company_profiles.id=1`。源文件与副本 SHA-256 一致。
- 发布独立公司介绍、Logo 和 3 条发展历程；旧来源和新来源的 20 个公开公司字段差异为 0，发展历程 3/3 逐项一致，官方社交链接均为 0。
- 发布动作写入审计日志。原内部公司记录、原 Logo 文件和历史历程未修改或删除。
- 可复核的只读结果见 [发布核验 JSON](website-company-publish-verify-20261102.json)。预检、备份和执行结果分别见同目录 `website-company-publish-{preflight,backup,result}-20261102.json`。

## 代码边界

- `WebsiteController` 的公司公开接口默认使用 `WebsiteNativeCompanyQueryService`、官网历程和官网社交链接服务；旧内部读取分支仅用于显式回退。
- 已发布公司资料通过 `PUT /api/website/admin/company-profile/published` 维护，受 `website.manage` 权限保护。更新前检查公开必填信息和官网 Logo 文件；新 Logo 为草稿时在同一事务内发布。后台保存前会提示变更立即对外可见。
- 官网 Logo 的发布检查接受有效草稿文件，发布公司资料时会一起发布该文件，避免只能选择已发布 Logo 却缺少发布入口。

## 验证与剩余条件

- 公司来源切换、资料发布与编辑、就绪检查、权限测试：本地定向 Maven 运行 19 项测试，通过 19 项，失败及错误均为 0（退出码 0）。
- 后台 `vue-tsc` 类型检查通过；后台及官网生产构建通过。官网构建仍提示若干历史静态图片路径在构建时无法解析，需在部署环境复查实际资源。
- 数据库发布后只读复核通过。当前后端 8081 未运行，且有待执行的 Flyway 版本，本轮未启动后端，因此尚无真实 HTTP 响应和浏览器验收记录。部署前仍需完成迁移审核、启动后的公开接口与页面检查。
- 本轮没有删除旧字段、旧表或媒体文件，也没有将产品公开来源一起切换。
