# 制程管理入口撤除记录（2026-11-02）

用户决定撤除新增的“制程管理”页面，以及“生产参考工期”中加入的产品制程版本配置和跟单详情的“调整本单制程”。全局跟单节点字典与车间默认流程在业务稳定前由代码和数据库迁移维护，不提供在线增删、排序或停用入口。生产参考工期仅维护产品节点参考天数。

本轮移除页面路由、导航、前端写 API 与后端对应写端点。保留节点定义只读接口、运行时目录、数据库表和既有任务快照，以保证生产跟单列表、详情、参考工期、历史记录的读取与计算不失联。旧任务快照不因撤除管理页面而重算。

只读实库核查时有两个气动转盘封口机试验产品版本（V1 已发布、V2 草稿），均无任务快照引用；另有 38 张 LEGACY 任务快照。此数据仅代表本次核查时点。V437 仅清理没有任务快照引用的气动转盘封口机试验版本，不删除任务快照。产品版本与本单调整写接口已撤除，氚云导入不再自动生成制程快照。历史快照的只读能力仍服务于既有跟单兼容逻辑。

后续调整全局字典或车间默认流程时，新增版本化迁移并配套回归验证；不修改已经执行的 Flyway 迁移。变更需核对节点编码、顺序、按需识别、完成率分母、旧任务快照和参考工期取值。
