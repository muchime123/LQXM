# 利强包装统一官网：双语言与部署边界

## 决定

- 继续使用 `corporate-website/` 一套 Vue 工程和一套设计系统。
- 中文站与英文站分别构建、分别部署；产品保留同一稳定 slug，文案、推荐顺序和 SEO 按语言维护。
- 两站只使用官网拥有的数据和媒体。内部档案变更不自动影响公开页面。
- 首版聚焦设备产品；包材页面暂停公开，旧地址转至产品中心。模具不公开展示。
- LQXM 官网内容后台可后续接入，首版静态快照先保证页面可浏览和联系方式有效。

## 现状与上线门槛

当前 `corporate-website` 只有中文页面与中文产品快照；`index.html` 的语言为 `zh-CN`，SEO canonical、站点地图和 robots 均固定为 `www.liqiangbz.com`。因此不能把同一构建产物直接绑定英文域名并宣称英文站已完成。

1. 确认两个域名的实际归属、备案与 DNS 配置，以及 `www` 与裸域名的规范地址。
2. 形成有审核责任人的英文公开内容：导航、首页、产品分类、产品详情、解决方案、公司介绍、联系方式和 SEO。技术参数与图片可复用官网独立资源。
3. 内容层以稳定 slug 关联中英文产品；缺少英文审核内容的产品不能出现在英文站，也不能自动回退展示中文。
4. 构建时显式指定 `zh-CN` 或 `en`，分别生成 `lang`、canonical、站点地图、robots 和内容快照。构建脚本应拒绝缺少目标语言内容的发布构建。
5. 只有两种语言的对应页面均已发布且可访问时，才生成互相指向的 `hreflang`；没有对应页面时不输出虚假的语言替代链接。
6. 在预览域名核对导航、产品详情、媒体、移动端、SEO 和联系渠道，再绑定正式域名。

## 内容模型

共享：产品稳定 ID / slug、分类关系、可公开技术参数、官网媒体 ID。

按语言维护：名称、摘要、详情、应用说明、首页推荐与营销表达、SEO 标题和描述。中文和英文可以采用不同的首页排序和展示集合。

联系信息按站点配置，公开邮箱或电话必须由业务人员确认。静态首版以邮件和电话为真实联系渠道；在线询盘表单应在有可用接收端后再开放。

## 实施顺序

1. 完成中文首版设备产品展示与预览部署。
2. 整理并审核英文内容与媒体授权，建立按语言加载的静态内容层。
3. 同一工程分别构建中文和英文站，核对域名、语言 URL、canonical 与 `hreflang`。
4. 两站稳定后，把语言内容维护接入 LQXM 官网独立后台，并设计静态发布流程。

本文件只确定边界；不改数据库、不发布英文占位内容，也不切换正式域名。
