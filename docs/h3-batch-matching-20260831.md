## 操作

1. 生成候选，查看来源编号、名称、规格、交易单位、目标档案和匹配依据。
2. 每页最多100项，可勾选表头选择本页，也可单选。
3. 核实目标和各行交易单位，勾选单位确认后保存。库存候选通过关联产品批次共用映射，不需要逐条映射库存。
4. 保存后刷新剩余候选。没有推荐的记录仍在原产品列表中，需要人工核实。

- 复用历史确认：来源ID、编号、名称、规格、单位全部一致，历史目标唯一且仍有效。不同批次出现相互冲突的确认时不推荐。
