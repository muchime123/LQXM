# B-3.3 年度期初更正影响预览（2026-10-27）

本轮仅实现更正前的只读测算。`GET /api/cashflow/accounts/opening/{id}/correction-preview?newAmount=...` 要求 `cashflow.manage` 和 `CASHFLOW=ALL` 数据范围。接口返回原金额、拟更正金额、差额、受影响账年，以及应用更正后是否需要重新财务确认；金额以十进制字符串返回，避免前端浮点误差。页面入口位于年度期初弹窗。

该接口不创建申请、不应用金额、不更改确认状态，也不生成幂等或审计记录。已确认期初的原确认历史继续保留。申请、应用、重新确认的写入流程及独立授权仍按 `cashflow-journal-next-stage-design-20261026.md` 单独实施，本轮不新增 Flyway 迁移。
