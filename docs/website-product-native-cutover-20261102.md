## 部署核验与保留风险

本轮未启动后端或触发待执行的 Flyway 迁移，尚无真实 HTTP 页面验收。部署后需确认没有 `APP_WEBSITE_PRODUCT_SOURCE=legacy` 环境覆盖，并检查 `/api/website/products`、首页精选、45 个详情 URL、图片内容、SEO 与筛选结果。官网构建仍提示少数历史静态图片路径在构建时不存在，属于另外的页面素材问题。

此次 SEO 是根据已有公开文字生成的基础版本；产品 ID 1 的图库使用单张卡片图；43 条精选标记需要后续运营筛选。这些不阻止数据源切换，但应列入上线页面审阅。旧 `ProductCatalogService` 分支与旧图片 URL 仍保留显式回退能力，稳定运行并验证无回退需求后再退役。
