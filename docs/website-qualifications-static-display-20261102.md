# 官网证照与专利展示收敛（2026-11-02）

证照和专利在官网仅作为少量图片展示，改由 `corporate-website/src/data/qualifications.js` 与 `public/images/` 维护。官网不再请求这两类 native 内容接口，也不再提供后台草稿、发布和双数据源开关。

现展示 1 张营业执照和 2 张外观设计专利证书。三张原件先前均已人工查看；本轮从官网独立媒体副本复制到官网工程的静态图片目录，逐张比对 SHA-256。页面仅写原件可证明的名称和证书类型，不把内部档案的“有效”状态当成对外的实时法律状态声明。

原静态清单中的 ISO 9001、CE、产品检测报告、连续式封口机、真空包装机和包装设备控制软件卡片缺少已核验的对应图片或身份，已从官网展示清单移除；它们的内部档案未删除。此前 `website_credentials`、`website_ip_items` 的草稿及官网媒体副本保留在数据库和存储中，未执行迁移、DROP 或清空。旧 Flyway 脚本保持不变，表结构退役另行评估。

修改证书展示时，先核对原件与可公开性，复制图片至官网 `public/images/`，再修改静态清单。官网构建时不需要连接数据库或档案文件服务。`corporate-website/tests/qualifications-assets.test.mjs` 验证每张展示图片都存在于官网工程。

展示卡片可用键盘聚焦，点击后在新标签页直接打开官网自有原图，方便阅读证书细节；不调用内部档案文件接口。
