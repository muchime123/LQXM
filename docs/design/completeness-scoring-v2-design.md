# 资料完整度评分 v2 — 四维分层加权模型

> 设计日期：2026-06-23
> 替代：旧版扁平 Pass/Fail 模型（`useArchiveHealth.js` + `ProductCatalogService.health()`）

## 1. 问题总结

| # | 旧模型问题 | 影响 |
|---|-----------|------|
| 1 | 等权重：缺主图和缺操作视频各占 1/6 | 无法区分关键缺失和次要缺失 |
| 2 | 二元打分：只有"有/无"，1 张图和 10 张图得分相同 | 无法激励内容丰富度 |
| 3 | 覆盖不全：仅覆盖 6-7 项，11 种素材只检查 3 种 | 大量存档内容被忽略 |
| 4 | 无分层溯源：看到 67% 不知道问题在哪 | 无法精准定位改进方向 |
| 5 | 前端/后端两套计算不一致 | 同一产品可能出现不同分数 |

## 2. 新模型结构

```
综合得分 = Σ(维度得分)
维度得分 = (维度内部 Σ 子项得分 / 维度满分) × 维度权重 × 100
```

### 2.1 四大维度及权重

| 维度 | 权重 | 定位 | 满分 |
|------|------|------|------|
| 基础信息 | 25% | 产品百科基础字段是否填全 | 100 分 |
| 视觉素材 | 30% | 图片/视频类素材覆盖与数量 | 100 分 |
| 技术文档 | 25% | 说明书/图纸/证书等文档 | 100 分 |
| 配置完整度 | 20% | SKU 参数与价格的细化程度 | 100 分 |

> 权重依据：食品包装设备行业，经销商选型时最关心"产品长什么样（视觉 30%）→ 基本参数（基础信息 25%）→ 技术证明（文档 25%）→ 报价与规格（配置 20%）"。

---

## 3. 维度一：基础信息（权重 25%）

检查 `product_models` 表的文本字段。

| # | 子项 | 字段 | 得分规则 | 满分 |
|---|------|------|----------|------|
| 1.1 | 产品名称 | `name` | 非空即满分 | 20 |
| 1.2 | 设备大类 | `equipmentCategory` | 非空即满分 | 20 |
| 1.3 | 所属车间 | `workshop` | 非空即满分 | 15 |
| 1.4 | 产品线名称 | `productLineName` | 非空即满分 | 10 |
| 1.5 | 在售状态 | `saleStatus` | 非空即满分 | 10 |
| 1.6 | 适用产品 | `applicableProduct` | 非空即满分 | 10 |
| 1.7 | 适用范围 | `applicableScope` | 非空即满分 | 5 |
| 1.8 | 机型 | `machineType` | 非空即满分 | 5 |
| 1.9 | 产品线代码 | `productLineCode` | 非空即满分 | 5 |

**维度计算**：`infoScore = Σ(子项得分) / 100 × 25` → 贡献到综合得分 0~25

**特殊规则**：1.1-1.3 为"关键必填"，缺少任一项时整个维度加标 ⚠

---

## 4. 维度二：视觉素材（权重 30%）

检查 `product_assets` 表中各类素材的存在与数量。

### 4.1 主图 `main_image`（满分 30）

| 数量 | 得分 |
|------|------|
| 0 张 | 0 |
| 1 张 | 20 |
| 2 张 | 25 |
| ≥3 张 | 30 |

### 4.2 SKU 图覆盖率 `sku_image`（满分 25）

以配置数 `V` 为基准，计算有 SKU 图的配置数 `S`。

| 覆盖率 | 得分 |
|--------|------|
| 0%（或无配置） | 0 |
| 1-49% | 8 |
| 50-79% | 15 |
| 80-99% | 20 |
| 100% | 25 |

### 4.3 场景图 `scene_image`（满分 15）

| 数量 | 得分 |
|------|------|
| 0 张 | 0 |
| ≥1 张 | 15 |

### 4.4 细节图 `detail_image`（满分 15）

| 数量 | 得分 |
|------|------|
| 0 张 | 0 |
| ≥1 张 | 15 |

### 4.5 参数图 `parameter_image`（满分 15）

| 数量 | 得分 |
|------|------|
| 0 张 | 0 |
| ≥1 张 | 15 |

**维度计算**：`visualScore = Σ(4.1~4.5) / 100 × 30` → 贡献到综合得分 0~30

## 5. 维度三：技术文档（权重 25%）

### 5.1 说明书（满分 35）

| 状态 | 得分 |
|------|------|
| 无附件/无草稿/无 Markdown | 0 |
| 有 Markdown 草稿 | 20 |
| 有默认附件文件 | 30 |
| 已发布（manualStatus = PUBLISHED） | 35 |

### 5.2 图纸 `drawing`（满分 20）

| 数量 | 得分 |
|------|------|
| 0 张 | 0 |
| ≥1 张 | 20 |

### 5.3 证书 `certificate`（满分 15）

| 数量 | 得分 |
|------|------|
| 0 张 | 0 |
| ≥1 张 | 15 |

### 5.4 宣传册 `brochure`（满分 15）

| 数量 | 得分 |
|------|------|
| 0 张 | 0 |
| ≥1 张 | 15 |

### 5.5 视频类 `device_video` / `operation_video`（满分 15）

| 数量 | 得分 |
|------|------|
| 都没有 | 0 |
| 有设备视频或操作视频 | 10 |
| 两者都有 | 15 |

**维度计算**：`docScore = Σ(5.1~5.5) / 100 × 25` → 贡献到综合得分 0~25

## 6. 维度四：配置完整度（权重 20%）

以第一条配置（或平均值）为检查对象。

### 6.1 存在配置（满分 25）

| 状态 | 得分 |
|------|------|
| 无配置 | 0 |
| ≥1 条配置 | 25 |

### 6.2 核心参数（满分 25）

检查字段：`packagingSpeed`、`voltage`、`power`、`deviceSize`、`deviceWeightKg`

| 已填项数 | 得分 |
|----------|------|
| 0 项 | 0 |
| 1 项 | 8 |
| 2 项 | 15 |
| 3 项 | 20 |
| ≥4 项 | 25 |

### 6.3 价格信息（满分 15）

| 状态 | 得分 |
|------|------|
| 都未填 | 0 |
| `dealerPrice` 或 `retailPrice` 至少一个 | 15 |

### 6.4 选配/规格（满分 15）

检查字段：`optionalDevice`、`equipmentSizeSpec`、`coverMaterial`、`heatingMethod`、`customMoldSupported`

| 已填项数 | 得分 |
|----------|------|
| 0 项 | 0 |
| 1 项 | 5 |
| 2 项 | 10 |
| ≥3 项 | 15 |

### 6.5 零部件品牌（满分 10）

检查字段：`plcControlSystem`、`touchScreenConfig`、`servoMotor`、`vacuumPump`、`cylinder`、`motorConfig`

| 已填项数 | 得分 |
|----------|------|
| 0 项 | 0 |
| 1 项 | 3 |
| 2 项 | 6 |
| ≥3 项 | 10 |

### 6.6 配置标识名（满分 10）

| 状态 | 得分 |
|------|------|
| 配置中无 `variantName` | 0 |
| ≥1 条有 `variantName` | 10 |

**维度计算**：`configScore = Σ(6.1~6.6) / 100 × 20` → 贡献到综合得分 0~20

## 7. 综合得分与等级

```java
综合得分 = infoScore + visualScore + docScore + configScore
// 范围：0 ~ 100
```

| 等级 | 分数范围 | 颜色 | 含义 |
|------|----------|------|------|
| 完整（Excellent） | 90–100 | 绿色 #059669 | 可直接用于客户展示 |
| 良好（Good） | 75–89 | 蓝色 #2563EB | 核心资料齐全，少量补充即可 |
| 一般（Fair） | 60–74 | 黄色 #D97706 | 可用但缺失较多，建议补全 |
| 不足（Poor） | 40–59 | 橙色 #EA580C | 关键项缺失，影响销转 |
| 缺失（Critical） | 0–39 | 红色 #DC2626 | 仅有产品名，急需完善 |

## 8. 前端呈现规划

### 8.1 概览页（CatalogOverviewTab）

- 四维雷达图（基础信息/视觉素材/技术文档/配置完整度）
- 每个维度展开可看子项明细
- 缺失项直接链接跳转（缺主图 → 跳素材 tab）

### 8.2 列表卡片/列表行

- 四维小指示器（4 个微型进度环，颜色统一）
- Hover 显示维度明细 tooltip
- 综合分大数字（列表行右侧）

### 8.3 健康度总览表（CatalogHealthPanel）

- 增加按维度筛选（只看基础信息不足的产品等）
- 表格列：产品名 → 四维得分 → 综合分 → 首要建议
