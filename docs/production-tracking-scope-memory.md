# 生产跟单范围 · 项目记忆

用户于 2026-11-02 明确：**生产跟单只跟已经开始生产跟单的部分生产任务单，不覆盖全部氚云生产任务单。**

今后修改生产跟单节点、制程快照、参考工期、P50/P75、节点分析、周复盘和交期分析时，必须区分：

- `production_orders`：氚云源任务全集，可用于候选任务查询、原始事实核对。
- 已纳入并开始跟单的任务：生产跟单业务范围。应有明确纳入事实或真实跟单操作；仅导入、仅创建空状态行、仅处于某个提交日期区间都不等于开始跟单。
- 产品制程模板：某产品以后开始跟单时的默认节点定义。发布模板不代表该产品全部历史源任务已经跟单。
- 任务制程快照：任务开始跟单时冻结的执行依据；氚云重复导入不能创建或改写快照。
- 历史工期样本：从已开始跟单的任务中，进一步筛出节点日期可信、流程可比较的样本。不能拿源任务总量充当样本数。

“待纳入候选任务”可以供跟单员查找和选择，但应与工作台的已跟单任务、进度分母、参考工期样本分开。停止跟单表示车间生产停止，恢复后继续使用原任务与快照。旧表导入和 Excel 回写暂不作为本轮建设重点。
