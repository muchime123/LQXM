## 3. 业务需要先回答的三个问题（对应你的复核要点）

1. **是真实停用的盒型？** → 选 C（保留历史）。
2. **是重复、合并后的旧规格？** → 选 B，并写明合并后的目标规格 ID。
3. **是历史导入被错误软删除？** → 选 A（恢复规格），并核对是否在售状态。

补充提醒：同一系列内部是否存在「尺寸相近的重复规格」，可用 SQL A4 的同系列有效规格候选辅助判断；规格名本身包含尺寸与克重（例如 260×170×30mm 20g 与 25g），判断重复时请以**尺寸+克重**为准，不要只看图片。

## 4. 执行与留痕方式（建议）

- 每次执行一条 INSERT-free 的**小批量 UPDATE**（按决策行分组：A 组一次、B 组一次），执行前只读预览影响行数，执行后复跑 SQL A1 校验剩余异常数 = 0（或 = 决策为 C 的行所含素材数）。
- 变更前后各留一次「按系列 × 规格」的快照，随决策表一起归档。
- 本表填写完成后，交由业务负责人签字（确认人列），再进入执行；不得由技术侧代为选择 A/B/C。
