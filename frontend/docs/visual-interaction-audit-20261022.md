## 视觉治理执行建议（不新增组件）

1. **先修 V1**（DefaultLayout 移动端塌陷）——全站性、可复现、修完可截图回归。
2. **V2-V6 属页面级小改**，每处 ≤ 半天，可与 P1 批次并行按页清。
3. **V8-V11 不改布局、只对齐令牌**：`--control-height-*`、`--btn-radius/--btn-font-size`、danger 三档色；生产跟单与 AssetToolbar 均不换组件。
4. **截图基建保留**：`_audit_shots/shoot.mjs` 可复用（改动后重跑对比），治理验收以"改动前后截图对照"为准。
